# Deep Research Skill

When this skill is activated, conduct rigorous, multi-faceted investigations across literature, technical archives, and code repositories:

1. **Multi-Source Scoping**: Parallelize exploration across general web indices, preprint repositories (arXiv), bibliographic databases (Semantic Scholar, CrossRef, OpenAlex), and code platforms (GitHub).
2. **Methodological Comparison**: Compare foundational theories, competing methodologies, and empirical trade-offs across scientific papers and practical architectures.
3. **Citation & Lineage Tracing**: Trace forward and backward citations, resolve DOIs to peer-reviewed versions, and assess historical trajectory against modern state of the art.
4. **Codebase Corroboration**: Search code repositories to confirm whether theoretical algorithms work in practice, noting real-world API signatures and execution benchmarks.
5. **Deduplication & Ranking**: Deduplicate cross-provider hits, filter superficial marketing content, and rank sources according to domain authority, citation counts, and semantic density.
6. **Thematic Synthesis**: Structure findings into cohesive thematic dimensions, contrasting consensus points against ongoing controversies and open challenges.
