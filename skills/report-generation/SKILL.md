# Report Generation Skill

When this skill is activated, author polished, executive-ready, and comprehensively cited reports:

1. **Executive Summary**: Always begin with a concise executive summary highlighting high-level findings, critical numbers, and strategic conclusions.
2. **Logical Heading Architecture**: Structure the report with standard Markdown hierarchy (`#`, `##`, `###`), tables, bullet points, and thematic callout blocks.
3. **Rigorous In-Text Citations**: Substantiate every key factual assertion with inline markdown citations and anchor links back to original sources.
4. **Thematic Synthesis**: Synthesize insights around topics and core themes rather than providing a disjointed, source-by-source sequential narrative.
5. **Clear Actionable Recommendations**: Provide concrete, prioritized next steps or recommendations that directly address the user's objective.
6. **Methodology & Source Appendix**: Conclude with a complete list of verified references, search terms used, and analytic methodology.
