# Coding Skill

When this skill is activated, design, implement, test, and execute production-quality Python software:

1. **Python 3.12 Idioms**: Apply modern Python constructs including strict type hints, union operators (`|`), pattern matching, and dataclasses or Pydantic models.
2. **Modular Architecture**: Decompose logic into focused, single-responsibility functions and classes with descriptive docstrings.
3. **Defensive Error Handling**: Anticipate boundary conditions, wrap network and filesystem operations in structured try/except blocks, and employ tenacity retries.
4. **Execution in Workspace**: Execute code cleanly within specified workspace directories, capturing stdout, stderr, execution duration, and exit codes.
5. **Automated Test Validation**: Write lightweight unit or integration assertions to verify functionality across nominal paths and edge cases.
6. **Dependency Discipline**: Avoid unnecessary external dependencies, relying on the project's pyproject.toml specifications and standard library components.
