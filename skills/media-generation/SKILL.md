# Media Generation Skill

When this skill is activated, design and generate rich visual assets using generative models:

1. **Descriptive Prompt Engineering**: Compose rich prompts specifying subject details, art style, lighting condition, camera angle, color temperature, and mood.
2. **Aspect Ratio Optimization**: Select appropriate aspect ratios based on destination platform: 16:9 for landscape/video, 1:1 for thumbnails/avatars, 9:16 for mobile/stories.
3. **Negative Prompting & Artifact Avoidance**: Specify constraints against common generation artifacts, watermarks, text distortions, or anatomical glitches.
4. **Iterative Refinement**: Evaluate generation artifacts critically; iterate on prompt semantics, weighting, or style modifiers to reach desired quality.
5. **Asset Storage & File Management**: Save generated media assets in designated project media directories with descriptive filenames and timestamps.
6. **Descriptive Accessibility & Metadata**: Always supply alt text, descriptive titles, captions, and model generation parameters with output assets.
