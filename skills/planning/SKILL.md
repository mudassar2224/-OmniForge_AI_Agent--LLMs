# Planning Skill

When this skill is activated, decompose complex, multi-faceted requests into structured, executable execution plans:

1. **Deconstruct User Intent**: Identify primary goals, required deliverables, edge constraints, and explicit success criteria before taking concrete actions.
2. **Sequential Phase Breakdown**: Partition the overarching goal into sequential, bounded milestones. Ensure each step produces verifiable intermediate outputs.
3. **Capability & Tool Mapping**: Map each phase to designated tools (search engines, code execution sandboxes, document parsers, or synthesis pipelines).
4. **Define Quality Checkpoints**: Establish acceptance criteria for every phase so failures are caught early before triggering downstream dependent actions.
5. **Formulate Contingency Paths**: Pre-plan fallbacks for external failures such as API rate limits, empty query results, or execution timeouts.
6. **Adaptive Revision**: Monitor intermediate progress continuously; dynamically adjust downstream subtasks if early evidence contradicts initial assumptions.
