# Data Analysis Skill

When this skill is activated, inspect, clean, aggregate, and visualize structured datasets:

1. **Schema & Null Inspection**: Load data (CSV, Parquet, Excel, JSON) into pandas DataFrames, inspecting column types, shapes, and null value distributions.
2. **Data Cleaning & Normalization**: Impute or drop invalid records, cast columns to appropriate data types, and normalize textual identifiers and datetime stamps.
3. **Statistical Characterization**: Compute descriptive statistics (mean, median, standard deviation, interquartile ranges, skewness, correlation matrices).
4. **Grouping & Pivot Aggregations**: Group records across key dimensions, perform time-series resamplings, and build pivot tables to surface hidden patterns.
5. **Visualization Generation**: Create readable, professional charts with clear labels, units, legends, and titles to communicate quantitative distributions.
6. **Data-Driven Synthesis**: Synthesize numerical observations into clear, evidence-based conclusions and actionable operational recommendations.
